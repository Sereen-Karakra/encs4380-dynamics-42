State-Space Control: Place the Poles

Take the mass-spring-damper model from Module 3 and choose where the closed-loop poles go. State feedback u = −Kx + N·r gives the response you ask for, directly from ζ and ωn.

Pole placementState feedback u = −KxOpen loop vs closed loop
The model

Mass-spring-damper in state space

m·x″ + b·x′ + k·x = u  |  x₁ = x, x₂ = x′
A = [ 0   1 ; −k/m   −b/m ],   B = [ 0 ; 1/m ],   C = [ 1   0 ]
Feedback: u = −k₁·x₁ − k₂·x₂ + N·r
Closed loop: m·x″ + (b + k₂)·x′ + (k + k₁)·x = N·r
Match to m·(s² + 2ζωn·s + ωn²):
k₁ = m·ωn² − k  |  k₂ = 2ζωn·m − b  |  N = k + k₁ = m·ωn² (so the final value equals r)

State feedback needs both position and velocity. On real hardware you measure position with a sensor and need a velocity measurement or an estimator (for example from the encoder). Large k₁ or k₂ also mean large forces, so a real actuator limit would cap how fast you can place the poles.

Method and AI use

Method: pole placement by matching coefficients. Because the plant is second order and fully measured, the closed-loop poles can be placed anywhere. The simulation uses our own RK4 solver on x′ = A·x + B·u with u = −K·x + N·r, the same approach as the phase plane in Module 3.
