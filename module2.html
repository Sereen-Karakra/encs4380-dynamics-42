2. Input and output sine waves (steady state)

Input x(t) = A sin(ωt). Sensor output y(t) = KAM sin(ωt + φ). The dashed reference Kx(t) shows the ideal response without frequency attenuation or phase delay. The waveform plot is steady state, so it does not include the initial transient.
