System equations

Sensor: τs dyₛ/dt + yₛ = y

Controller: e = r − yₛ; u = clip(Kp·e + Ki·∫e dt − Kd·dyₛ/dt, −Umax, +Umax)

The sensor is a first-order system in the feedback path. The PID controller uses the sensor reading yₛ, not the true output y. The derivative term acts on the measured signal, so a setpoint step causes no derivative kick.

05

Why a slow sensor causes oscillation

The controller reacts to an out-of-date picture of the output. By the time the sensor reports that the target is reached, the plant has already moved past it, so the controller keeps pushing. A larger τs adds phase lag to the loop and removes damping.

Plant τ·dy/dt = K·u − y, P control only: (τs + 1)(τs·s + 1) + K·Kp = 0
ωn = √((1 + K·Kp)/(τ·τs)),   ζ = (τ + τs) / (2·√(τ·τs·(1 + K·Kp)))

The sensor also adds a zero to the response from r to y, so the real overshoot is larger than the ζ-based formula for a plain second-order system. The ringing frequency still follows ωn and ζ.

Important: with P only and a first-order plant, a slow sensor adds ringing but never makes the loop unstable. Add integral action (Ki), derivative action, or a second-order plant, and the loop can become unstable. Try the “Slow sensor + PI” scenario.
