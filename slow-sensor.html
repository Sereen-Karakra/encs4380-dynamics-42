System equations

Plant: first or second order, as selected above

Sensor: τs dyₛ/dt + yₛ = y

Controller: e = r − yₛ; u = clip(Kp·e + Ki·∫e dt − Kd·dyₛ/dt, −Umax, +Umax)

The sensor is a first-order system in the feedback path. The PID controller uses the sensor reading yₛ, not the true output y. The derivative term acts on the measured signal, so a setpoint step causes no derivative kick.

Feedback architecture

Inside the feedback loop

The plant output is available as y(t). Only the sensor measurement yₛ(t) returns to the controller, so delays in the feedback path affect the response.

Understand the behavior

Why delay affects stability

The controller reacts to a delayed view of the true output. The plant can pass the target before the measurement catches up, causing overshoot and ringing. Increasing the sensor time constant adds phase lag and can reduce closed-loop damping.

Plant τ·dy/dt = K·u − y, P control only: (τs + 1)(τs·s + 1) + K·Kp = 0
ωn = √((1 + K·Kp)/(τ·τs)),   ζ = (τ + τs) / (2·√(τ·τs·(1 + K·Kp)))

The true-output transfer function includes a zero, so a standard second-order overshoot formula does not directly predict the real overshoot. The ringing frequency still follows ωn and ζ.

Important: For a first-order plant with positive P-only gain, the linear closed loop remains stable even if the sensor becomes slow, although ringing may increase. Other controller and plant combinations can become unstable. Try the “Slow sensor + PI” scenario.
